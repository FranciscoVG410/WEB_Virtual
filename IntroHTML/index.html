¿Que es HTML?

HTML (Hyper Text Markup Lenguage) es el lenguaje estandar para la estructura de las paginas Web

Etiquetas Basicas

  • html: Define un docuento html.
  • head: Contiene informacion o metadatos deñ documento.
  • body: Contiene el contenido visible de la pagina.
  • title: Muestra el titulo de la paina.

    Etiquetas principales

    1. h1-h6: Muestra los encabezados
    2. p: ingresar parrafo
    3. ol-ul: Representacion de mi lista
    4. b: Convierte el texto en negritas
    5. br: Break o salto de linea
    6. hr: linea horizontal divisora
    7. a: Conecta a una liga de referencia
    8. img: Se utiliza para colocar imagenes
