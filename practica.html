Introduccion a Git

Comandos Basicos

  • git init: Inicializa un repositorio
  • git status: Verifica el estado de mi archivo
  • git add: Agrega archivos al area de preparado
  • git commit -m: Agrega los archivos añ area de preparado
  • git pull: Obtiene la ultima version del sistema
  • git push: Manda la version al repositorio remoto
  • hit log: Muestra las versiones/commits de mi sistema

Branching

  • git branch nombre_branch: Crea una nueva rama
  • git checkout nombre_branch: Te dirige a la rama indicada
  • git branch: Muestra las ramas existentes
